Por favor, adicione a imagem da logo "Aconteceu Hoje" nesta pasta com o nome `logo.png`.

- Formato: PNG (com fundo transparente se possível)

A logo será exibida no cabeçalho da página de perfil com dimensões de 120x120 pixels.
